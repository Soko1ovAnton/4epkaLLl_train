# Дневник тренировок (GymLog)

Android-приложение для фиксации силовых тренировок: календарь, тренировки, подходы,
дропсеты, каталог упражнений и статистика с расчётом 1ПМ.

## Возможности

- **Календарь** — месячная сетка; в любой день можно добавить тренировку
  (запланировать) или начать её сразу. Завершённые дни отмечены точками.
- **Экран тренировки** — добавляй упражнения из каталога или создавай свои
  прямо на месте; записывай подходы: **вес × повторы**, отметка «отказ»,
  **дропсеты** (несколько ступеней со сбросом веса без отдыха), заметки,
  перемещение упражнений вверх/вниз. Автоподстановка весов с прошлого раза.
- **Каталог упражнений** — ~70 готовых упражнений с целевой и побочными
  группами мышц; поиск, фильтр по группе, свои упражнения, скрытие/удаление.
- **Статистика** — график прогресса, **1ПМ по формуле Эпли**, лучший подход,
  общий тоннаж, число подходов и дней в зале, таблица рабочих весов от 1ПМ
  (95%…60%), история последних подходов.
- Тёмная тема, всё на русском.

## Установка

Скачай `GymLog-v1.0.apk` на телефон и открой файл — Android предложит
установку (разреши установку из неизвестных источников для браузера/проводника).
Минимальная версия Android: **8.0 (Oreo, API 26)**.

`GymLog-v1.0-debug.apk` — отладочная сборка (то же самое, но больше размер
и отладочные метки). Достаточно одной из двух; release-версия предпочтительна.

## Сборка из исходников

Портативный тулчейн уже лежит в репозитории (`.tools`, `.sdk`), интернет нужен
только первый раз для Maven-зависимостей:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1              # debug
powershell -ExecutionPolicy Bypass -File scripts\build.ps1 -Release     # release
```

Готовые APK: `app\build\outputs\apk\{debug,release}\`.

## Подпись release

- `gymlog-release.keystore` — ключ подписи (пароли в `keystore.properties`).
- **Сохрани эти два файла**: без них нельзя будет выпустить обновление,
  которое установится поверх установленного приложения.

## Структура проекта

```
app/src/main/java/com/chepkall/gymlog/
  data/        Room: Exercise, Workout, WorkoutExercise, ExerciseSet + DAO
  stats/       Формулы 1ПМ (Эпли), рабочие веса, округление до блинов
  seed/        Стартовый каталог упражнений
  ui/calendar/ Календарь (сетка месяца + тренировки дня)
  ui/workout/  Экран тренировки, диалог подхода/дропсета
  ui/library/  Каталог упражнений, bottom-sheet выбора
  ui/stats/    График (кастомный View), карточки статистики
  util/        Даты, диалоги ввода
```

## Данные

База SQLite (`gymlog.db`) хранится в приложении. Удаление приложения
удаляет данные; бэкап включён через Android Auto Backup.
